# Football stats site

This repo contains a small football stats dashboard built with React + TypeScript + Vite.

## Run locally

```bash
cd football-stats
npm install
npm run dev
```

## Build

```bash
cd football-stats
npm run build
npm run preview
```

## What’s inside

- Dashboard: league summary + goals-by-matchweek chart + top-6 table
- Teams: standings table (includes xG diff)
- Team detail: form (last 5) + key players
- Players: sortable/filterable leaderboard
- Matches: filterable results table (includes xG)
