# Football Stats (Sample)

Offline football stats dashboard (sample dataset).

## Run

```bash
npm install
npm run dev
```

## Build / preview

```bash
npm run build
npm run preview
```

## Pages

- Dashboard: league totals + goals by matchweek chart + top-6 table
- Teams: standings table (includes xG diff)
- Team detail: recent form + key players
- Players: sortable/filterable leaderboard
- Matches: filterable results table (includes xG)
